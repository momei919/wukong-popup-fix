# 洛克王国页游悟空神辅脚本弹窗修复工具

一个用于消除「悟空神辅II」打开时反复出现的 **IE 脚本错误弹窗** 的 Windows 小工具。单文件、免安装、无需管理员权限。

悟空每次更新版本，exe 文件名都会变化（例如 `悟空神辅II 2.5.2.9.exe` → `悟空神辅II 2.5.3.0.exe`），原来登记的兼容设置随之失效，弹窗便会再次出现。本工具每次运行都会重新扫描所选目录、识别其中**最新版**的悟空程序并写入对应登记，同时清理旧版本残留，因此升级后只需点一次「一键修复」即可恢复，不必手动改注册表。

当前版本：**v1.0.0**

---

## 问题现象

打开「悟空神辅II」时，会在两个时机弹出脚本错误提示：

1. 刷新 / 进入游戏、出现 QQ 快捷登录二维码的瞬间
2. 点击快捷登录、成功进入游戏之后

弹窗内容通常是：

```
当前页面的脚本发生错误。

是否继续在此页面上运行脚本程序?

行: 0
Char: 0
错误: Script error.
代码: 0
URL: ...
```

点「是」能继续用，但每次登录都要点，且遮挡界面。

## 原因

悟空神辅的内嵌浏览器控件（IE / Trident）默认以 **IE7 文档模式** 渲染登录页。快捷登录二维码来自跨域脚本，在旧文档模式下抛出的异常会被浏览器掩码成 `Script error. 行0 Char0 代码0`，于是每次加载都弹一次。

这不是悟空本身的 bug，也不是系统故障，而是「WebBrowser 控件默认仿真版本过低」这个老问题。

## 修复原理

在注册表里按 **exe 文件名** 登记 IE11 文档模式：

```
HKCU\Software\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION
    悟空神辅II 2.5.2.9.exe = 11001 (DWORD)
```

- `11001` 表示以 IE11 标准模式渲染
- 只影响当前用户（HKCU），不需要管理员权限
- 不修改悟空程序和游戏文件
- 按文件名生效，因此悟空每次更新版本号变化后，需要对新文件名重新登记——这正是本工具存在的意义

## 功能

| 功能 | 说明 |
|---|---|
| 一键修复（登记最新版） | 扫描所选目录，按版本号取最新的 `悟空*.exe`，登记为 IE11 模式（11001） |
| 清理残留（删除失效项） | 删除注册表中「悟空*」开头、但对应 exe 已不存在的条目，避免越积越多 |
| 保留旧版 | 勾选后填一个旧版 exe 文件名，该版本的注册表项不会被清理 |

附加行为：

- 自动排除工具自身，不会把修复工具当成悟空程序
- 只处理文件名包含「悟空」的注册表项，不动其他软件
- 支持勾选「包含子目录」递归扫描
- 目录、勾选项会自动保存，下次打开沿用

## 使用方法

1. 下载 `洛克王国页游悟空神辅脚本弹窗修复工具.exe`
2. 放到悟空所在目录，或该目录下的任意子文件夹（例如 `修复工具\`）
3. 打开程序，「程序所在目录」选择 **悟空 exe 所在的目录**
4. 保持「一键修复」「清理残留」勾选，点「执 行」
5. 看到「完成：登记 1 条，清理 N 条」即可

> 建议：悟空目录里只保留一个正在使用的 `悟空*.exe`，并取消「包含子目录」，可避免把备份目录里的旧版/副本误判为最新版。

## 配置与数据

| 内容 | 位置 | 是否落盘 |
|---|---|---|
| 配置 `settings.json` | 工具 exe 同目录 | 是 |
| 运行日志 | 仅窗口内显示 | 否，关闭即消失 |

## 从源码构建


或手动执行：

## 常见问题

**Q：点执行后提示「未找到含「悟空」的 exe」？**
目录选错了。选的是「悟空 exe 所在的目录」，不是修复工具自己的目录。工具不会自动向上级目录查找。

**Q：登记成功但弹窗还在？**
确认实际运行的那个 exe 文件名与登记的一致。若目录里有多个 `悟空*.exe`，工具只登记版本号最高的那个。

**Q：悟空更新后要做什么？**
直接再点一次「执 行」即可，工具会自动登记新版本并清理旧版本残留。

**Q：安全吗？**
只读写 `HKCU` 下一个注册表键、只操作名字含「悟空」的值。可随时在注册表编辑器中删除这些项回滚，不会影响系统或游戏。

**Q：支持 Windows 10 吗？**
支持。窗口圆角设置仅在 Win11 生效，Win10 上自动忽略。
